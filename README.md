A tiny program that writes one funny line to a text file. The line is 127
characters: a librarian is fired for shushing the fire alarm, and explains
that the books were sleeping and the smoke was just thinking out loud.
The program checks the line before writing it, so the file stays inside
the 140-character limit, and it writes plain UTF-8 text with no trailing
newline, exactly one line.

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` (`OUTPUT_DIR` overrides
the directory). Running it twice produces byte-identical output.
